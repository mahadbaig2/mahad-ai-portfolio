# Mahad AI Product Engineering Portfolio

An intentionally over-engineered portfolio site and demonstrable AI system ("Talk to Mahad"). Designed to showcase deep end-to-end AI product engineering, architectural discipline, strict cost-capped infrastructure, and inspectable AI workflows.

---

## Architecture Overview

- **Frontend**: Next.js App Router (`apps/web`) with strict TypeScript, Tailwind CSS, and Server-Sent Events (SSE) streaming.
- **Content Management**: Sanity Studio (`apps/studio`) owning all structured source-of-truth content.
- **AI Backend**: FastAPI (`apps/api`) orchestrating LangGraph workflows, deterministic routing, and in-process ONNX query router.
- **Vector Retrieval**: Qdrant vector database (`mahad_portfolio_chunks`) with embeddings generated by `intfloat/multilingual-e5-small`.
- **Operational Persistence**: Neon PostgreSQL managing source documents, chunk manifests, ingestion runs, and feedback.
- **Voice Capabilities**: Groq Whisper for speech-to-text; isolated OpenVoice V2 container (`apps/voice`) for experimental voice output.
- **Pipelines**: Offline ingestion (`pipelines/ingestion`), ML classifier training (`pipelines/training`), and LangSmith evaluation (`pipelines/evaluation`).

## Local Prerequisites

- **Node.js**: `v20.x` or higher
- **pnpm**: `v9.x` or higher (`v11.x` supported)
- **Python**: `3.11.x` or higher
- **Docker & Docker Compose**: (Optional, for local PostgreSQL and Qdrant instances)

---

## Quickstart

1. **Clone and Install Dependencies**:
   ```bash
   pnpm install
   ```

2. **Environment Configuration**:
   ```bash
   cp .env.example .env
   # Populate your API keys in .env
   ```

3. **(Optional) Start Local Storage Services**:
   ```bash
   docker compose up -d
   ```

4. **Verify Monorepo Health**:
   ```bash
   pnpm lint
   pnpm typecheck
   pnpm test
   ```
