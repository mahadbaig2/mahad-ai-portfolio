# Architecture Decision Records (ADRs)

This directory documents key architectural decisions for the Mahad AI Portfolio.

## Index
- `ADR-001`: Sanity as authoring source of truth.
- `ADR-002`: Neon PostgreSQL as operational source of truth.
- `ADR-003`: Qdrant as rebuildable derived vector index.
- `ADR-004`: FastAPI and LangGraph on Hugging Face CPU Basic Space.
- `ADR-005`: In-process ONNX query routing model.
- `ADR-006`: MLflow for classical/deep ML; LangSmith for LLMOps.
- `ADR-007`: Separate failure domain for OpenVoice voice service.
- `ADR-008`: SSE instead of WebSockets/WebRTC for version 1.
